# Haldor: Ostatni z Wygnanych
Przeglądarkowa gra akcji/platformówka z RPG. Historia i grafiki koncepcyjne: Artur.

## Zawartość
- 5 krain × 6 etapów + Tron Popiołu (31 etapów), 6 bossów
- 5 broni (miecz, włócznia, łuk, topór, magia) na kole broni, mistrzostwo i kuźnia każdej
- 5 pieczęci odblokowuje sztuki walki; wspomnienia Haldora po każdym władcy
- Tryb klasyczny (życia) lub z ogniskami; 3 sloty zapisu
- Pułapki: wahadła, miażdżyciele, słupy ognia, ruchome i spadające platformy, wiatr, wzbierająca lawa
- Własne przypisanie klawiszy i przycisków pada, sterowanie dotykowe
