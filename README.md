# Haldor: Ostatni z Wygnanych
Przeglądarkowa gra akcji/platformówka z RPG. Historia i grafiki koncepcyjne: Artur. Kod: Claude (5.11.2026).

## Jak zainstalować jako aplikację (GitHub Pages)
1. Załóż darmowe konto na github.com i utwórz repozytorium, np. `haldor`.
2. Add file → Upload files → przeciągnij WSZYSTKIE pliki z tego folderu → Commit.
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/root` → Save.
4. Po 1–2 min gra jest pod adresem `https://TWOJA-NAZWA.github.io/haldor/`.
5. Telefon (Chrome): menu ⋮ → "Zainstaluj aplikację" / "Dodaj do ekranu głównego". Komputer (Chrome/Edge): ikona instalacji w pasku adresu albo przycisk ZAINSTALUJ GRĘ w menu gry.

## Zawartość
- 5 krain × 6 etapów + Tron Popiołu (31 etapów), 6 bossów
- 5 broni (miecz, włócznia, łuk, topór, magia) na kole broni, mistrzostwo i kuźnia każdej
- 5 pieczęci odblokowuje sztuki walki; wspomnienia Haldora po każdym władcy
- Tryb klasyczny (życia) lub z ogniskami; 3 sloty zapisu
- Pułapki: wahadła, miażdżyciele, słupy ognia, ruchome i spadające platformy, wiatr, wzbierająca lawa
- Własne przypisanie klawiszy i przycisków pada, sterowanie dotykowe
